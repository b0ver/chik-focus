# Правила разработки

- Изменять исходники в `dist/`; `docs/` генерируется `node scripts/build.mjs`.
- Перед коммитом: `node scripts/check.mjs` и `node --test tests/*.test.mjs`.
- Для исправлений бронирования, хранения и обработки сбоев добавлять регрессионные тесты.
- Работать в ветке, проверять diff, проводить изменения через PR и успешный CI.
- Секреты, контакты участников, локальные настройки и резервные копии не коммитить.
- Перед релизом сверяться с `OPERATIONS.md`; изменения данных и Apps Script требуют отдельного плана отката.
- Не считать локальные тесты проверкой живого сервера или запуском CI на GitHub.
